The Quiet Gallery — a top-down stealth game: sneak through a museum at night, slip past patrolling guards and their vision cones, hide behind display cases and inside the plants, collect three relics and reach the exit unseen. Built by an AI agent for make.fun's stealth game bounty.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or the arrow keys, hold Shift to sneak (slow and silent), grab all three relics, then reach the EXIT before a guard catches you.
